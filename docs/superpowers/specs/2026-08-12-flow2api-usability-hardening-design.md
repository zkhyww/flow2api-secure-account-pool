# Flow2API 本地账号池易用性与稳定性补强设计

## 目标

在不重写 Flow2API 现有账号池、日志和安全底座的前提下，补齐四个已由真实操作暴露的缺口：浏览器添加账号、影策定制插件自动配对、测试页免填 API Key、图片 2K 放大的 reCAPTCHA 身份一致性。底座全部通过后，再由影策作为普通客户端接入统一 API。

## 已确认事实

- 三个 Google 账号已进入本地账号池；当前两个启用、一个由用户临时禁用。
- 用户通过只保留目标账号启用的方式，已验证第二个账号可以完成基础图片生成。
- 上述验证发生在 Flow2API 自带 `/test` 页面，不代表影策已经接入。
- `extension.zip` 是影策定制插件；仓库 `extension/` 是精简 Worker，二者不能混用。
- 2K 模型先成功生成原图，再在 `upsampleImage` 阶段收到 `PUBLIC_ERROR_UNUSUAL_ACTIVITY: reCAPTCHA evaluation failed`，最终正确回退原图。
- 影策定制插件的验证码响应只有 token；扩展模式后端随后清空请求指纹。放大代码还有内外两层重试，最坏可形成九次上游尝试。

## 不可破坏边界

- 不修改 `D:\codex项目\Framefield-Studio` 及其任何 worktree。
- 不 push、不创建 Issue/PR、不发布、不部署。
- 不读取、输出、打包或持久化 Cookie、Profile、账号密码、令牌、完整媒体 URL、原始提示词或浏览器状态。
- 日志和测试证据只保留 stage、probe、error class、status、token id、route connected、has media、attempt count 等白名单字段。
- 继续使用 Flow2API 原有账号数据模型、调度、并发、冷却、熔断和观测能力；不创建第二套账号池。
- 真实测试只使用无敏感内容、单图片、最低必要分辨率；每次提交前先有自动测试锁定行为。

## 设计

### 1. 一键浏览器添加账号

管理页新增“浏览器添加账号”。后端为一次添加会话生成短时、单次使用的配对标识，幂等地启动一个隔离 Chrome Profile，并自动加载影策定制插件。页面轮询只返回公开状态：等待浏览器、等待登录、导入中、成功、已存在并更新、失败、超时。成功或空闲后沿用现有浏览器回收机制关闭窗口。手工 Token 新增保留为备用。

### 2. 插件自动配对与版本身份

影策定制插件是唯一施工对象。插件包增加清晰的定制版标识和可测试的能力版本。服务地址、Route Key、Client Label 均由添加会话自动设置。长期总 API Key 不进入 URL、控制台或插件持久存储；插件用一次性配对凭证换取可撤销的插件会话授权。每个 Chrome Profile 保持独立实例标识和账号绑定。

### 3. 测试页免填 API Key 与指定诊断账号

同源 `/test` 页面优先使用现有 HttpOnly 管理员会话，向后端申请短时测试能力；前端不读取管理 Cookie，也不长期保存全局 API Key。登录失效时提示重新登录。手工 API Key 输入移到高级设置，继续兼容外部测试。测试页增加仅管理员可用的“指定账号”诊断入口；正式公开 API 仍由账号池自动调度。

### 4. 2K 放大验证码一致性

扩展验证码响应改为结构化 bundle，仅包含 token 和允许的浏览器身份元数据：User-Agent、Accept-Language、UA client hints，以及必要时的同一网络出口标识；不包含 Cookie、Profile 或完整 URL。后端把 bundle 绑定到请求上下文，`upsampleImage` 沿用同一 token id、route key、project id、session id 和浏览器身份。每次失败都获取全新验证码。只保留一层最多三次的放大重试；失败仍返回原图，并明确标记 `original_fallback`，不能宣称 2K 成功。

### 5. 管理页加载可靠性

修复 `checkAuth is not defined`。账号请求尚未完成或失败时显示“加载中/加载失败”，不得显示为“0 个账号”。页面提供重试入口，不改变后端账号数据。

## 验收

- 所有新增行为先有自动测试 RED，再最小实现 GREEN。
- 管理页按钮不会因重复点击多开浏览器；插件自动加载；添加状态不泄露凭据。
- 新 Profile 登录 Flow 后可自动导入或更新正确账号。
- `/test` 在已登录后台时无需输入 API Key；退出后能力立即失效。
- 指定账号测试只选择目标账号，结束后不改变其他账号启用状态。
- 2K 放大成功时返回真实放大媒体；失败时最多三次并明确回退原图。
- 运行仓库全量 pytest、静态凭据扫描、页面合同测试和相关真实 smoke。
- 最终只生成本地干净 commit，不 push。
